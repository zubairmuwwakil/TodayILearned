# Prompt Engineering MOC

## Purpose

Prompt engineering is the practice of designing instructions, context, constraints, examples, and output requirements so an AI system is more likely to produce a useful result.

It is not the same as traditional programming:

| Traditional code | AI prompt |
|---|---|
| Usually deterministic | Usually probabilistic |
| Executes formal syntax | Interprets natural-language instructions |
| Has explicit control flow | Predicts a response from context |
| Can be tested exactly | Must be evaluated for quality and correctness |

## High-Value Mental Model

A useful prompt normally answers:

> **What should be done, using what information, under which constraints, and in what form?**

A role or persona may help, but it is optional. Clear tasks, relevant context, success criteria, and output requirements usually matter more.
