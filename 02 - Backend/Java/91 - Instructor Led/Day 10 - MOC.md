## One-Minute Summary

- A Set stores unique elements.
- A Map stores unique keys mapped to values.
- `Hash*` implementations prioritize average fast lookup.
- `LinkedHash*` implementations preserve a predictable order.
- `Tree*` implementations maintain sorted order.
- A Stream processes data through a source, intermediate operations, and a terminal operation.
