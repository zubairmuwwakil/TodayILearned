## High-ROI Study Method

Use this cycle:

1. Read the note once.
2. Cover the examples.
3. Answer the recall questions from memory.
4. Trace the code by hand.
5. Do the mini practice.
6. Add mistakes to [[Scanner Mistakes]] or your personal mistake log.

## Spaced Review Plan

Let the **Spaced Repetition** plugin schedule reviews (it adapts intervals per card via SM-2). Write each note's Recall Questions as `#flashcards` cards (see [[Polymorphism]] for the format) and review with `Cmd/Ctrl+P → Review flashcards`.

Manual fallback if you skip the plugin — review after: same day, 1 day, 3 days, 7 days, 14 days.

Either way: **focus on retrieval, not rereading**, and mix topics (interleave) once you've studied each at least once.
