Pro tip: You can also enable auto-refresh in Eclipse settings:

  

• Go to Eclipse → Preferences → General → Workspace

• Check "Refresh using native hooks or polling"

  

This makes Eclipse monitor external file system changes automatically, though it can have a slight performance impact on large projects.

  

So the folders are definitely being created (as you see in Finder), Eclipse just needs a refresh to pick them up! 👍
